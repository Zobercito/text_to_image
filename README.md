# 📝 Txt2Img Converter

A simple and lightweight desktop application built in Python using Tkinter. It converts any code snippet or text into a high-resolution JPG image, perfect for sharing on social media or in documentation.

## ✨ Features

* **Minimalist Interface:** Compact dark mode window.
* **High Resolution:** Automatically generates sharp, HD images suitable for printing or zooming.
* **Smart Naming:** Saves files with timestamps (e.g., `imgtxt_2024...`) to prevent duplicates.
* **Code Editor Style:** Uses a dark background and monospaced font to mimic a coding environment.

## 🚀 Requirements

* Python 3.x
* `Pillow` library
* Tkinter (usually included with Python)

## 📦 Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/Zobercito/text_to_image.git
    cd txt2img-converter
    ```

2.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
    *(Note: On Linux/Ubuntu you might need to run: `sudo apt install python3-pil python3-tk`)*

## 🛠️ Usage

Run the main script:

```bash
python3 text_jpg.py
